# Домашняя работа 16.2 в рамках проекта разработки функциональности e-commerce для онлайн магазина.На данном этапе реализовано создание объектов классов Product и Category в одноименных модулях.

## Установка:

- Клонируйте репозиторий
```git clone https://github.com/McSim555/E_commerce_project```
- Откройте проект bank_application в PyCharm версии >= 3.14

## Использование:

1. Откройте ветку feature/homework_16_2
``` git branch feature/homework_16_2 ```

2. В модуле product.py описано создание объектов класса Product с заданными атрибутами. 
   - Определен магический метод __str__ для класса Product
   - Определен магический метод __add__ для сложения продуктов
   
3. В модуле category.py класса Category с заданными свойствами, в этом модуле также реализованы счетчики категорий и продуктов на уровне класса.
   - Определен магический метод __str__ для вывода общего количества продуктов в категории
   - Метод add_product() модифицирован таким образом, чтобы можно было добавлять только родственные объекты класса Product

4. В модуле smartphone.py создан класс-наследник Smartphone от класса Product
  - Для класса Smartphone магический метод модифицирован таким образом, что можно складывать только объекты одного класса

5. В модуле lawngrass.py создан класс-наследник Lawngrass от класса Product
  - Для класса Lawngrass магический метод модифицирован таким образом, что можно складывать только объекты одного класса

6. В модуле baseproduct создан базовый абстрактный класс с именем BaseProduct,
   который является родительским для класса продуктов.
   Классы Smartphone и Lawngrass остались наследниками класса Product.

7. В модуле ifo_product_mixin реализован класс-миксин, который при создании объекта печатает в консоль информацию о том, 
   от какого класса и с какими параметрами был создан объект.

   Например: Product('Продукт1', 'Описание продукта', 1200, 10)
   Миксин добавлен в цепочку наследования класса Product

8. Откройте файл main.py и запустите код.
   Создаются объекты описанных классов на основе тестовых данных модуля main.py. 
   В консоль выводятся заданные данные.
