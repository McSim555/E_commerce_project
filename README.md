# Домашняя работа 14.2 в рамках проекта разработки функциональности e-commerce для онлайн магазина.На данном этапе реализовано создание объектов классов Product и Category в одноименных модулях.

## Установка:

- Клонируйте репозиторий
```git clone https://github.com/McSim555/E_commerce_project```
- Откройте проект bank_application в PyCharm версии >= 3.14

## Использование:

1. Откройте ветку feature/homework_14_2
``` git branch feature/homework_14_2 ```

2. В модуле product.py описано создание объектов класса Product с заданными атрибутами. 
   - Создан класс-метод new_product({данные нового продукта}, <категория>.product_list()), который создает новый продукт и при этом проверяет, есть ли такой же продукт по name 
   в данной категории. Если есть, то устанавливается большая цена, а количества складываются.
   - Созданы сеттер и геттер price

3. В модуле category.py класса Category с заданными свойствами, в этом модуле также реализованы счетчики категорий и продуктов на уровне класса.
   - Создан метод добавления нового продукта в категорию add_product()
   - Так как метод __products теперь приватный, создан метод get_products() для получения информации о продуктах в категории
   - Геттер products возвращает информацию о продуктах в виде строк
   - Метод products_list возвращает продукты категории в виде списка словарей по продуктам
   
4. Откройте файл main.py и запустите код.
   Создаются объекты описанных классов на основе тестовых данных модуля main.py. 
   В консоль выводятся заданные данные.


5. Тестирование
   В ходе проекта для тестирования использовался фреймворк тестирования pytest
   Для их запуска выполните команду: ```pytest```
