# Домашняя работа 14.1 в рамках проекта разработки функциональности e-commerce для онлайн магазина.На данном этапе реализовано создание объектов классов Product и Category в одноименных модулях.

## Установка:

- Клонируйте репозиторий
```git clone https://github.com/McSim555/E_commerce_project```
- Откройте проект bank_application в PyCharm версии >= 3.14

## Использование:

1. Откройте ветку feature/homework_14_1
``` git branch feature/homework_14_1 ```

2. В модуле product.py описано создание объектов класса Product с заданными атрибутами. 
   В модуле category.py класса Category с заданными свойствами, в этом модуле также реализованы счетчики категорий и продуктов на уровне класса.

3. Откройте файл main.py и запустите код.
   Создаются объекты описанных классов на основе тестовых данных модуля main.py. 
   В консоль выводятся заданные данные.


4. Тестирование
   В ходе проекта для тестирования использовался фреймворк тестирования pytest
   Для их запуска выполните команду: ```pytest```
